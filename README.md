# Java 2D Game

A 2D game developed in Java for a university project.

The game has three levels, different obstacles and enemies, and a menu where the player can start the game or change the settings.

## Technologies

- Java
- Java Swing and AWT
- SQLite
- Object-Oriented Programming (OOP)

## Features

- Three game levels
- Player movement and collision detection
- Enemies and obstacles
- Main menu and settings
- Saving game data using SQLite
- Tile-based maps and 2D graphics

## Project Structure

- `src` – Java source code
- `res` – Images and level maps
- `diagrama` – UML diagrams

## How to Run

1. Open the project in IntelliJ IDEA.
2. Set up a Java JDK.
3. Mark `src` as Sources Root and `res` as Resources Root.
4. Add the SQLite JDBC library to the project dependencies.
5. Run `PaooGame.Main`.

The audio files are not included in this repository.
